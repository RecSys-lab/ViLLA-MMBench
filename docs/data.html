Data Modules Documentation

MovieLens Module (movielens.py)

Functions:

  • downloadMovieLens(url, dest, VERBOSE=True): Downloads MovieLens dataset files
  • loadGenres(download_path_prefix: str, DATASET: str) -> pd.DataFrame: Loads genre information for movies
  • prepareML(config: dict): Prepares MovieLens dataset with specified configurations, including k-core filtering and train-test splitting

Modalities Module (modalities.py)

Function:

  • prepareModalities(config: dict, train_df: pd.DataFrame, test_df: pd.DataFrame)
    • Loads and processes text, visual, and audio embeddings
    • Merges different modalities
    • Handles NaN/Inf values
    • Creates modality-specific image and feature objects
    • Implements dimensionality reduction (PCA, CCA)
